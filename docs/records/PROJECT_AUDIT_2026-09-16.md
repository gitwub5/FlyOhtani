# 현재 폴더와 실험환경 진단

2026-09-15~16 · 소스·문서·현재 셸을 읽고 확인했다. 구현은 변경하지 않았다.

## 전체 판단

현재 프로젝트는 **1관절 공 가로채기 환경에 제어기를 연결하기 위한 초기 연구 뼈대**다. 실제 연결망, SNN 학습, 검증된 물리 baseline은 아직 없다. 환경·제어기·인코더·분석의 분리는 유지할 가치가 있다.

| 위치 | 실제 상태 |
| --- | --- |
| `envs/` | MuJoCo XML, 11차원 관측, 1차원 행동, 보상 구현. runtime 미검증 |
| `controllers/scripted.py` | 거리 기반 스윙. 성공률 미검증 |
| `controllers/mlp_policy.py` | 무작위 NumPy MLP 추론. PPO가 사용하는 모델과 별개 |
| `controllers/snn_policy.py` | 입력→LIF→출력의 순방향 toy 회로. 재귀 연결·학습·연결망 없음 |
| `controllers/brian2_stdp_controller.py` | 인터페이스만 있고 실제 기능은 미구현 |
| `encoders/` | 좌표·상태의 확률 스파이크화. 실제 망막 영상 입력은 아님 |
| `train/train_ppo.py` | SB3 PPO 학습·저장 호출 존재. 설정·평가·실험 로그 미연결 |
| `train/train_stdp.py` | 미구현 안내만 존재 |
| `demos/record_episode.py` | scripted 실행과 콘솔 출력. 영상 녹화 없음 |
| `analysis/` | `.npy` 시각화 도구. 실행기에서 원자료를 저장하는 경로 없음 |
| `configs/default.yaml` | 설정 초안. 이를 읽는 실행 경로 없음 |

## 우선순위별 문제

### P0. 공의 발사식과 중력

`envs/fly_batter_env.py:99`의 초기 속도는 `(target - ball_pos) / flight_time`이다. XML은 중력 `-9.81 m/s²`를 사용한다. 자유 비행에서 목표 시각의 높이는 목표보다 `0.5 × 9.81 × T²`만큼 낮다. 현재 T=0.72~0.95 s에서는 **2.54~4.43 m** 차이다. 목표 높이는 0.52 m이므로 목표 전에 지면에 부딪힐 가능성이 높다.

이는 식에 대한 정적 계산이다. 실제 충돌·튕김·타격 성공률을 측정한 것은 아니다. 중력을 보정한 궤적 또는 명시적인 무중력 과제를 먼저 선택한 뒤 스윙을 조정해야 한다.

### P0. 접촉 검사와 지표의 의미

- `envs/fly_batter_env.py:117`: 2 ms 적분을 5회 한 뒤 접촉을 검사한다. 중간에 발생하고 끝난 접촉은 놓칠 수 있다. substep별 사건을 모아야 한다.
- `timing_error`: 공이 기준 x 좌표에 도착하기까지의 시간이며 실제 스윙 오차가 아니다.
- `contact_velocity`: 공 선속도(m/s)와 관절 각속도(rad/s)를 더한다. 접촉점 상대 선속도로 정의해야 한다.
- `energy_cost`: 정규화 행동값의 제곱이며 물리 에너지가 아니다. 제어 비용으로 명명하거나 기계적 일을 별도 계산해야 한다.
- 시간 패널티의 매 step 누적과 접촉 시 조기 종료로 비행시간·제어 간격에 따라 보상이 달라진다. 평가 지표를 보상과 분리해야 한다.

### P1. 신경 시간과 감각 조건

SNN·인코더 기본 dt=2 ms, 환경의 행동 간격=10 ms다. 아직 통합 실행 루프가 없으므로 이미 실행 중인 결함은 아니다. 이후 환경 step당 신경 update를 한 번만 하면 시간이 5배 어긋난다. 물리·신경·감각·행동 시계와 출력 집계 구간을 명시해야 한다.

MLP는 11개 관측값, BallStateEncoder는 6개, RetinaEncoder는 x·z 위치만 쓴다. 그대로 비교하면 모델 효과와 정보량 차이가 섞인다. RetinaEncoder는 세계 좌표 기반 위치 인코더로 설명해야 한다.

### P1. 연구 목표와 구현 경로

현재 계획의 PPO→SNN 교체는 강화학습 정책 비교에는 적합하지만, 생물학적 내부 가소성의 검증을 자동으로 제공하지 않는다. 새 연구 방향에는 실제 회로 데이터 처리, 학습 위치 정의, 조건화 실험, 기억 보존·제거 실험이 필요하다.

설정·시드·체크포인트·원자료 저장·분석이 연결되지 않았다. 프로젝트 안에 lockfile과 실제 `tests/`, `.git` 항목도 없다. 상위 폴더 전체의 Git 관리 여부를 조사한 결과는 아니다.

### P2. 물리 스케일과 문서 차이

팔 길이 0.58 m, 공 질량 0.145 kg은 실제 초파리 몸의 스케일이 아니다. 추상 타격 장치로 명시하거나 생체 모델을 별도로 사용해야 한다. `human` 렌더링은 창 표시가 없고, `rgb_array`는 영상으로 저장되지 않는다. SNN 주석은 막전압 출력이라고 하나 구현은 스파이크 출력을 쓴다.
