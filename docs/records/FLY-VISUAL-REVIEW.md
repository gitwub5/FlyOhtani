# I-08a 외형 재검토와 I-08a-fix 인계

2026-09-16 · Codex 검토. 구현 변경 없이 현재 소스, 저장 영상 첫 프레임, MuJoCo reset 상태, 원본 wheel을 대조했다. 전체 테스트 재실행은 하지 않았다.

## 판정

**원본 취득은 확인됐지만 외형 적용은 미완료다.** 61개 테스트 통과 보고와 중앙 타구 불변은 올바른 외형/접지의 증거가 아니다. 기존 I-08a 완료 보고는 취득·부분 구현 기록으로 보존하고 아래 수용 기준을 우선한다.

- 로컬 wheel SHA256 `5db9bb89b7f57e2fda8d716fd8205b0ba7ac9a46e7c194ea6e752e38964f390d`는 [PyPI 1.2.1 배포 메타데이터](https://pypi.org/pypi/flygym/1.2.1/json)의 값과 일치한다. 저장된 STL **45개 모두** wheel의 동명 파일과 바이트 단위로 일치했다. XML 선언은43개이며 LFTarsus1/RFTarsus1 두 파일은 미사용이다. “43개만 vendoring”은 정확하지 않다. 기존 manifest에는 개별 STL 해시 목록이 없어 신규 검토 증거 JSON에 기록했다.
- `scripts/build_fly_visual_asset.py`는 발 geom 중심의 최저 z를 로컬0으로 맞춘다. 그런데 그 결과를 `baseball_park_b1.xml`의 **world z=1.0인 batter_body 내부**에 넣어 다시1m 올렸다. 로컬 좌표와 월드 좌표를 혼동한 배치 오류다.
- 월드 메시 정점으로 측정한 뒷발 최저 높이는 LH **0.920263m**, RH **0.920255m**다. 중간발은 LM1.068321m/RM1.061728m다. 지면은z=0이므로 시점 착시가 아니다. 중심을 발바닥으로 취급하기 때문에 단순히1m 내리면 약8cm 묻히는 별도 오류도 남는다.
- 몸통K=400, 앞다리K=1200은 의도적으로 넣은 **앞다리만3배 확대**다. 원본 메시 변조는 없지만 해부학적 비율이 보존되지 않는다. 떠 있는 몸에서 측정한1.265m 도달거리를 근거로 팔을 늘리는 것은 좌표 오류를 해결하지 못한다.
- 앞다리는 Tarsus를 생략하고 Femur/Tibia를 별도 IK로 배치한다. 손끝/관절 연결은 실제 메시 부착 프레임으로 검증해야 한다. 도달거리 clamp만으로 실제 손끝이 그립에 닿는다고 판정하지 않는다.
- 기존 계획의 중간+뒷다리 지지 표현도 사용자 의도와 달랐다. 아래 **뒷다리2개 지지**로 대체한다. 이 직립 타자 자세는 연구용 원본 외형을 이용한 의인화이며 실제 파리의 자연 자세나 균형 역학 재현은 아니다.

## 다음 작업: I-08a-fix

### 고정할 외형 요구

1. 머리에 가까운 앞다리 LF/RF로 배트 손잡이의 서로 다른 두 위치를 잡는다.
2. 뒷다리 LH/RH만 양발로 서고, 양쪽 발끝은 타자 박스 안 지면에 놓인다. 중간다리 LM/RM는 몸 옆에 자연스럽게 접어 두며 지지대나 추가 팔로 쓰지 않는다. 여섯 다리의 구분을 보존한다.
3. 원본 모든 부위에 동일한 uniform scale을 사용한다. 앞다리만 늘리기, 프레임별 길이 변경, 늘어나는 메시를 금지한다. 원본 관절 연결 프레임과 발끝(Tarsus 포함)을 보존하고 필요한 단순화는 실제 끝점과 외형을 검증한다.
4. 기존 배트의 물리 궤적·질량·관성·접촉 설정을 유지한다. 먼저 시각 몸의 월드 위치/방향, 공통 배율, 관절 자세, 손잡이 안 그립 위치를 함께 맞춘다. 기존 batter_body를 옮겨 물리 배트까지 이동시키지 않는다.

### 구현 순서

1. 원본 정상 자세와 변환된 직립 자세를 같은 배율로 나란히 렌더링한다. root/parent/world 좌표 변환을 명시하고 발 geom 중심이 아닌 실제 sole/end-effector 기준으로 접지한다.
2. **팔의3배 확대를 제거한 상태**로 뒷발 접지·앞다리 도달성을 함께 풀어야 한다. 준비→가속→접촉→감속→정착 전 구간에서 각 어깨와 그립 거리, 원본 관절 가동범위, 관절 연결점/발끝/그립 오차를 기록한다. 뿌리 위치만 내리거나 길이만 줄여 완료하지 않는다.
3. 양립 가능한 자세가 없으면 실패 프레임·필요 거리·가능 거리를 정량 보고한다. 조용히 팔다리를 늘리거나 목표를 clamp해서 완료로 처리하지 않는다. 물리 스윙/피벗 변경이 필요하면 별도 설계 변경으로 분리한다.
4. 정면·측면·포수 뒤·그립 근접에서 준비/접촉/정착 정지 화면을 먼저 확인하고, 통과 후 같은 시간축1×영상을 기록한다. 목·몸통·다리 접합부의 틈/관통, 중간 다리 겹침도 검사한다.
5. 실제 사용/미사용 파일 개수와 파일별 해시, 원본 rig 획득 경로·해시, 배율과 변환을 manifest에 갱신한다. 이 검토의 출처 확인은 메시의 바이트 동일성이지 재포즈의 정확성 보증이 아니다.

### 완료 기준 (설계값)

- 양쪽 뒷발 각각 월드 sole 지면 오차 ≤5mm, 준비부터 정착까지 수평 미끄러짐 ≤5mm. 발이 박스 안인지 좌표로 검증한다. 시각 접지는 실제 하중 지지 증명과 구분한다.
- LF/RF 실제 발끝–그립 오차 각각 ≤5mm 전 프레임. 관절 부착점의 추가 분리 오차 ≤2mm(원본 기준). 가동범위 위반/IK 불능을 별도로 실패 처리한다.
- 모든 부위 배율 동일, 전 프레임 뼈 길이 불변. 원본에서 생긴 틈과 변환이 만든 틈을 구분해 기록한다.
- physics overlay on/off의 DOF/actuator/관련 질량·관성 및 물리 궤적 불변을 기존 규약대로 검증한다. 렌더용 변경이 정책 관측을 바꾸면 관측 버전을 기록한다.
- 위 수치와 실제 정면/측면 영상 모두 통과해야 외형 완료로 표기한다. 현재61개 테스트 결과만 재제시해서 완료로 처리하지 않는다.

범위: 이 외형 수정 우선. I-08b 전신 역학, 나머지8코스 재보정, B2/변화구/RL은 이번 작업에 섞지 않는다.
