# 타격 운동 연결과 파리 모델 적용 검토

2026-09-17 · status: research/proposed. 현재 구현 규약을 대체하지 않는다. 사용자 요청으로 기존 타이밍 실험 착수에 앞서 메커니즘을 검토했다. 구현/실험은 하지 않았다.

## 결론

하체 지지–몸통 회전–팔/배트 협응 원리는 적용 가능하다. 그러나 현재 외형에 회전 애니메이션을 추가하는 것만으로 타격 역학은 변하지 않는다. 기존 B1은 기준선으로 보존하고 별도 실험 모델에서 질량·관성·관절·지면 접촉·토크 전달 경로를 설계해야 한다. 인간의 골반–허리 구조를 파리에 숨겨 넣고 생물학적 모델이라고 부르지 않는다.

근육/액추에이터가 에너지의 원천이고 지면은 지지/외력·모멘트를 제공한다. 이상적인 고정·무미끄럼 접촉점은 움직이지 않으므로 지면반력이 그 점에서 직접 양의 일을 공급한다고 해석하지 않는다. 토크 합산만으로 전달을 설명하지 않고 관절 power=torque×상대각속도와 에너지 변화를 기록한다.

## 현재 코드의 한계 (실제 소스 확인)

`envs/assets/baseball_park_b1.xml`의 batter_body는 joint 없이 world에 고정돼 있다. mass55의 몸통이 있어도 동적 자유도가 없다. bat_hinge와 bat_tilt_hinge만 구동하며 앞다리 mocap/시각 IK는 배트를 따라간다. 뒷다리 접지는 메시 위치 검증이고 하중 지지가 아니다. 따라서 현재 모델에는 하체 토크→몸통→앞다리 전달을 측정할 수 있는 경로가 없다.

## 대안 비교

| 선택 | 가능한 주장 | 한계 |
| --- | --- | --- |
| 외형만 몸통/발 회전 | 자연스러운 영상 | 역학·비거리 효과 없음 |
| 고정 기반 + 동적 흉부 yaw + 상대 스윙/틸트 | 몸통/배트 관성 결합·타이밍 효과 | 바닥 고정축의 반력이 받쳐줌. 실제 뒷다리 사용을 입증하지 못함 |

| 원 크기의 NeuroMechFly 전신 모델 | 실제 파리 신경근육 연구에 더 가까움 | 사람 크기 야구 과제와 다른 질량/시간/힘 스케일 및 과제 필요 |

권고: 두 번째를 짧은 역학 진단 단계로 쓰고, 사용자 목표의 완성은 세 번째로 둔다. 새 이름은 가칭 KC-01로 하며 기존 I-08b 실제 파리 전신 통합과 구분한다. 직립·양발 타격은 의인화된 공학적 몸이라는 점을 명시한다.

## 제안 단계

### KC-01a: 몸통 회전이 참여하는 최소 역학 모델

- 기존 B1/XML/controller를 동결하고 별도 profile/environment를 만든다. torso_yaw를 실제 유한 관성 몸체에 추가하고 그 자식으로 상대 swing/tilt를 둔다(총3개 능동 회전축 후보).
- 자유도를 늘리는 것과 더 큰 모터를 붙이는 효과를 구분한다. 몸통 잠금/몸통만/팔만/동시/시차 구동을 비교한다. 같은 새 하드웨어에서 조건을 비교하고 고정된 총 양의 기계적 일 예산·피크 출력/토크 제한을 함께 보고한다. 기존 B1과의 비교는 질량 분포가 달라지므로 별도 표다.
- 몸통 시각 자세만 옮기지 말고 관성/피벗/반작용 토크를 실제 모델에 넣는다. 고정 지지축의 외력·모멘트를 기록하며 이 단계의 발은 아직 시각용임을 분명히 한다.
- 질량/관성/가동범위/구동한도는 원래 static55kg이나 gear30을 그대로 가져오지 않는다. 확대 모델 단위·전체 질량 분배를 정하고 무공 운동부터 보정한다. 인간 문헌의 최고속도를 목표값으로 억지 맞추지 않는다.
- 배트 접촉점 속도는 몸통/상대 스윙의 실제 합성 운동에서 계산한다. 코스·토크 명령은 새 관측/행동 계약으로 버전 분리한다. 기준 score/재료는 고정하고 궤적 조정에 따른 차이를 본다.

### KC-01b: 뒷다리 지지와 실제 전신 전달 (사용자 목표)

- 몸통은 world 고정 해제. 뒷다리2개의 관절과 유한 면적 발 접촉으로 지지한다. 점접촉2개에 임의 yaw torque를 주지 않는다. 중간다리 접기·앞다리 그립 외형은 유지한다.
- 다리 힘→단일 흉부의 위치/회전→앞다리/배트 전달을 구현한다. 인간 허리 관절을 발명해 흉부를 둘로 분할하지 않는다. 복부는 필요 시 질량/균형 요소로 다루되 pelvis로 명명하지 않는다.
- 두 앞다리는 부하를 전달하는 실제 관절 사슬이어야 한다. 배트와 양손의 폐루프 구속/그립 힘을 설계한다. 한쪽 강체 연결+반대쪽 구속 같은 단순화도 가능하지만 과구속·구속이 하는 일·반력/침투 오차를 검사한다. mocap 손 위치 강제 이동으로 동적 배트를 밀지 않는다.
- 먼저 직립 균형→무공 체중 이동/흉부 회전→무공 스윙→tee/저속 공→현재 중앙 직구 순서. 정상 지지 검증 전 고속 타격부터 튜닝하지 않는다.
- 발바닥은 준비·정착에 안정적으로 접지하되 실제 heel lift/pivot/체중 이동을 허용할지는 새 계약에 명시한다. 기존 시각 규약의 전 구간 발 위치 불변을 무조건 적용하면 체중 이동을 막는다. 실제 침투·미끄럼·마찰·지면반력 검증으로 대체해야 한다.

## 필수 측정과 수용 설계

- 각 관절 q/qdot/torque/power, 양의 일/흡수 일, 몸통·배트 운동에너지, 지지/그립 반력, 발 접촉·미끄럼, 전체 질량중심, 배트 궤적, 출구속도/각도/score를 공통 시간축으로 기록한다.
- 닫힌 계의 운동량 보존을 지면에 고정된 모델에 요구하지 않는다. 지면/고정축 외력·액추에이터 일·접촉/감쇠 손실을 포함한 에너지/운동량 수지를 점검한다. 결합 구동에서 무한히 에너지가 생기면 실패다.
- 최대 점수만 비교하지 않는다. 동일 조건·자원 예산에서 조준 정확도/성공 시간창/점수 분포/에너지/정착·균형의 tradeoff를 본다. ±5ms 시험은 폐기하지 않고 각 새 모델의 진단으로 포함한다. 몸통 추가가 취약성을 해결한다고 선결론 내리지 않는다.
- timestep 수렴, 무입력, passive/locked 조건, 기계적 일 예산 일치, 손/발 구속 오류를 검증한다. 제어비용 ∫u²dt는 실제 joule이 아니므로 에너지 비교를 대체하지 않는다.
- 수치 임계값은 새 관성/단위/정상 지지 baseline을 정한 뒤 구현 전에 고정한다. 미측정 질량·토크·가동범위를 사실처럼 제시하지 않는다.
