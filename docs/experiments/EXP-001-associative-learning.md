# EXP-001 — 연합학습과 기억

규약 버전: 0.1-draft · 2026-09-16 · **실행 전 연구 선택이 필요한 초안**

## 질문

실제 연결망 기반 회로의 내부 가소성이 새로운 자극–보상 관계를 저장하는가? 외부 출력층은 고정한다. 결론은 선택한 회로·모델·가소성 가정의 범위로 한정한다.

## 실험 흐름

1. 초기 상태 W0를 저장하고 자극 A/B의 훈련 전 반응을 측정한다.
2. A+보상, B+중립을 제시해 내부 연결을 학습시킨다. 절반의 반복에서 A/B 대응을 뒤집는다.
3. 학습 후 W1과 전체 상태를 저장한다.
4. W1에서 각각 분기해 보상·가소성을 끈 즉시/지연/상태 초기화 probe를 수행한다.
5. 동일한 probe 시작 상태에서 W0 복원과 W1 이식을 비교한다.
6. 별도 분기에서 보상 관계를 뒤집고 재학습을 검사한다.

## 비교 조건

- 실제 회로 + 내부 가소성 + 고정 readout: 주조건.
- 동일 회로 + 가소성 꺼짐: 일시적 활동과 입력 편향 통제.
- 동일 회로 + 자극과 독립적으로 섞은 보상: 보상 횟수·크기를 맞춰 연합 통제.
- 보상만 제공: 비특이적 반응 통제.
- 차수·연결 수·흥분/억제 특성을 가능한 한 맞춘 재배선: 배선 기여.
- 내부 고정 + 학습 readout: 외부 학습의 기여를 보는 별도 비교.

재배선 조건이 기본 활동조차 유지하지 못하면 실패 원인을 보고하고 생물학적 구조의 학습 우위로 곧바로 해석하지 않는다.

## 주 평가 설계

고정 readout의 ‘보상과 연결된 자극 선호’ 방향을 시험 전에 정의한다. 자극 정체성에 따른 부호 편향이 없도록 보상 대응을 뒤집은 반복도 같은 방향으로 점수를 정렬한다.

각 독립 시드에서 `학습 변화 = 훈련 후 점수 − 훈련 전 점수`, `가소성 효과 = 주조건의 학습 변화 − 가소성 꺼짐 조건의 학습 변화`를 구한다. 섞인 보상 조건과도 같은 비교를 한다. 학습 시드가 반복 단위이며 trial들을 독립 학습 반복으로 취급하지 않는다.

원 반응, 변환한 선호 점수, 시드별 효과, paired 구간 추정과 실패를 함께 기록한다. 신경 반응을 선호 점수로 해석하는 근거가 없으면 ‘자극별 신경 반응 차이’로만 보고한다.

## 통과 기준의 틀

- 효과가 사전에 정한 최소 의미 크기와 불확실성 기준을 충족.
- 보상·학습 중단 및 빠른 신경 상태 초기화 후에도 효과 유지.
- 학습 전 연결 복원 시 효과 감소, 학습 후 연결 이식 시 효과 회복.
- 보상 대응 반전과 재학습에서 기대한 방향의 변화.
- 자극 노출량, 보상량, readout, 시험 절차가 비교 조건 간 일치.

위 항목은 판정 구조이며 숫자 기준은 아직 정하지 않았다. 실제 생물학과의 대응은 원 논문 재현 항목과 인공 과제 결과를 분리한다. 음성 결과도 완료된 실험으로 기록한다.
