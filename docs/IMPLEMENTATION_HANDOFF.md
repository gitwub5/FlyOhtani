# Claude 구현 인계

2026-09-16 · 사용자와 Codex가 계획·설계를 담당하고, 실제 코드·테스트는 사용자와 Claude가 진행한다. 이 문서는 작업 명세이며 완료 보고가 아니다.

## 착수 순서

**I-01 → I-02**, 이후 **I-03은 독립 작업**, **I-04는 연구 선택을 기다리며 합성 fixture 기반의 기반 기능까지 진행 가능**, **I-05는 EXP-001 확정 후** 진행한다. 사용자가 지정한 범위가 우선한다. 전면적인 폴더 이동이나 모든 단계의 일괄 구현을 요구하지 않는다.

### I-01. 실행환경과 현재 상태 확인

- 프로젝트 전용 Python/의존성 환경을 선정하고 최소 core와 RL/SNN 옵션을 분리한다.
- 논문 재현 환경과 프로젝트 실행 환경의 버전 충돌 가능성을 조사하고 실제 설치 조합을 고정한다.
- 초기 import·환경 로드·패키징·수치 실행을 검증한다. 새 모듈 추가 시 배포 패키지 포함도 확인한다.
- 운영체제·의존성·backend·소스 식별자를 기록하고 소스/데이터/실행 결과 저장 정책을 마련한다.

**완료 증거:** 정확한 환경 조합과 재현 명령, 실제 성공·실패 결과, lockfile. 렌더링은 별도 검사로 둔다. 런타임 검증과 학습 성공을 구분한다.

### I-02. 설정·공통 기록·상태 계약

- [구조 계약](ARCHITECTURE.md), [설정 명세](../configs/README.md)에 맞춰 최소 실행기·검증·저장 경로 구현.
- 기존 YAML을 실제 실행에 연결할지 legacy 전용으로 둘지 명시. 적용되지 않는 설정을 성공으로 표시하지 않음.
- 시드·단위·실행 상태·설정 형식 버전·checkpoint 분리 구현.
- 신경·물리 시계, probe 분기, fast/slow/trace reset 계약을 작은 합성 모델로 확인.

**완료 증거:** 설정 변경이 실제 출력에 반영됨; 잘못된 설정 거부; 동일 seed 재현; 중단·재개 비교; 평가 중 학습 상태 불변; probe 간 상태 오염 없음. 합성 검사는 실제 연결망 학습 결과로 보고하지 않는다.

### I-03. 기존 타격 환경의 결함 수정

근거: [정적 진단](PROJECT_AUDIT_2026-09-16.md). 아래 항목은 아직 수정되지 않았다.

| 수정 항목 | 완료 기준 |
| --- | --- |
| 발사 속도에 중력 보정 | 무동작 자유 궤적이 의도한 목표를 허용 오차 안에서 지남; 지면에 먼저 충돌하지 않음 |
| 물리 substep별 접촉 수집 | 중간 step 접촉 누락 없음, 최초 시각 보존, 한 접촉의 중복 보상 방지 |
| 접촉점 상대 선속도 | 선속도·각속도 단위 혼합 제거, 알려진 운동으로 검증 |
| 타이밍 평가 | ‘도착까지 시간’과 실제 행동/접촉 오차 분리, 실패 시 결측 이유 명시 |
| 제어 비용 | 행동 제곱은 제어 비용으로 명명; 물리 에너지는 계산한 경우에만 별도 표시 |
| 보상·종료 의미 | hit/miss/지면 접촉/시간 제한을 구분; 제어 주기 변경 효과와 누적 보상 점검 |
| 관측·baseline | 같은 정보 조건 정의, scripted·무동작·무작위의 검증 궤적 비교 |
| 렌더링·녹화 설명 | 실제 지원 기능과 이름·문서를 맞춤; 필요 시 창/영상 구현은 별도 단위 |

현재 중력 환경의 의도를 유지하는 발사식 보정을 기본 방향으로 한다. 무중력으로 변경하면 다른 과제로 표시한다. 타이밍의 세부 정의와 허용 오차는 물리 측정 규약에 먼저 적는다.

**완료 증거:** 결정적인 쉬운 궤적의 성공/실패 재현, 접촉 사건 원자료, 단위 및 환경 API 검사. 기존 랜덤 궤적의 성공률은 측정값으로 보고하며 목표 숫자를 임의로 소급 설정하지 않는다.

### I-04. 실제 회로·가소성 구성

- Q-01~04 확정 후 dataset loader·회로 ID·경계·부호·조절 신호를 구현한다.
- 원 논문 프로토콜을 재현하고 선택한 dt에서 수치 안정성·입력 세기별 반응을 검증한다.
- 학습 연결만 갱신하며 비대상 연결과 고정 readout의 불변성을 검증한다.
- 실제 전달물질 정보와 모델에서 가정한 효과를 분리해 기록한다.

**선행 조건:** [설계 결정](DECISIONS.md)의 논문·데이터·회로·방정식. 결정 전에도 loader 계약, 합성 데이터와 상태 저장 검사는 가능하다.

**완료 증거:** 출처 manifest, 실제 ID 연결, 원 프로토콜 재현 결과, 모델링 가정, fast/slow/trace 분류표. 기존 toy SNN에 이름만 붙여 실제 회로라고 보고하지 않는다.
