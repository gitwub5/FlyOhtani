# VM-01 — 시각·파리 몸 기반 학습으로 전환

2026-09-17 · status: ready · 사용자 승인에 따른 현재 작업 명세. Codex는 설계/검토, Claude는 아래 구현/테스트를 수행한다. [PLAN](../PLAN.md) D15~D18을 따른다.

## 목표와 중단할 작업

목표는 보이는 공을 주어진 몸으로 유효하게 쳐내는 정책을 학습하고, 이후 실제 연결 데이터 기반 회로 내부 학습을 검증하는 것이다. 인간식 몸통 선행·동방향 회전·고정 스윙 변위·팔로우스루를 정답 동작으로 강제하지 않는다. 고정된 몸의 물리적 한계/관절 범위/출력/정상 충돌은 유지한다.

KC-01a 후보 탐색, 몸통 단독 gear 재보정, KC-01b 직립 하체 확장은 보류한다. 기존 환경/회귀/철회 기록은 삭제하지 않는다. 기존 방향 필터는 옛 인간식 조건의 검증으로 한정하며 새 학습환경의 보편적 유효성 판정으로 가져오지 않는다.

## 이번에 수행할 작업

### V1. 눈 영상과 공 추적 — 구현/테스트 승인

1. [VISION-01](../design/VISION-01.md)의 허용/금지 입력을 바탕으로 head 부착 카메라와 별도 영상 관측 인터페이스를 구현한다. RGB/그레이스케일 일반 카메라 기준선이며 복안 재현으로 부르지 않는다. 현재 고정 fly_pov를 눈 센서로 재사용하지 않는다.
2. 투구를 렌더링해 기록하는 읽기 전용/비접촉 진단부터 시작한다. 스윙 후보가 성공하거나 KC 물리가 수렴하기를 기다릴 필요가 없다. 원본 B1/KC 결과와 구분된 output/profile로 저장한다.
3. 실제 camera extrinsics/intrinsics, resolution/FOV/fps, capture/available timestamp, latency, camera/head pose를 manifest에 남긴다. 자기 몸/배트 가림을 포함하고 정책 영상에 텍스트 overlay를 넣지 않는다.
4. 기존 해상도/FOV 후보를 비교하고 이미지에서 보이는 공 크기·가시 구간·검출 오차를 측정한다. 투영식은 사전 추정일 뿐 검출 성공의 증거가 아니다. geometry ground truth/segmentation은 평가자가 label 생성에만 쓴다.
5. 고전적 영상 검출/시간 추적 기준선을 만든다. 정책 경로는 픽셀·카메라 보정·시간 정보·명시된 자기감각만 사용한다. 정답 공 위치/속도/도착시간/코스·정답 trigger는 금지한다. 미검출 시 정답 fallback 금지. 단일 카메라 보정값만으로 2D점의 3D 깊이가 정해지는 것은 아니며, 알려진 공 크기나 운동모델을 사용하면 가정으로 명시한다.
6. 별도 진단 profile에서 릴리스 시각·초기 위치/속도의 작은 변동, 가림/동결/지연 조건을 구현해 시간표 암기를 점검한다. 이는 승인된 관측 평가 범위이며 기존8코스/변화구 구현과는 구분한다. 개발/평가 seed·범위·분할은 실행 전에 고정하고 평가로 검출기를 튜닝하지 않는다.
7. 위치 오차·검출 precision/recall·추적 단절·관측 age·추정 불확실성을 거리/가시 여부별로 보고한다. 모든 프레임 detected=true를 검출률 성공으로 취급하지 않는다. 영상 동결에도 차이가 없다고 무조건 시각 미사용으로 단정하지 말고 변화가 있어야 하는 자극 구간/입력 의존성을 함께 검사한다.
8. 합성 이동점 단위 검사, 실제 렌더 추적, 카메라 head 추종, clock/지연, 금지 채널 누출 검사를 수행한다. 산출물: 눈 영상+평가 전용 추적 overlay, dev/test 지표표, 관측 schema와 실행 명령. 이번 V1은 추적 평가이며 학습/타격 폐루프 성공 주장이 아니다.

### P1. 충돌 검증 — 독립 소규모 실험 구현/테스트 승인

1. 배트·몸통 제어 없이 공–고정 타격면/배트, 이어서 알려진 질량·관성의 자유 배트 충돌을 분리한다. 크기·질량·속도·접촉 위치·각도를 기록한다. 고정 표면은 외부 지지 반작용이 있으므로 자유계 운동량 보존을 잘못 요구하지 않는다.
2. 현재 접촉 파라미터를 재현하고 timestep/solver 변화, 관통·접촉시간·반발·충격량·에너지 수지를 확인한다. 깊이 약5cm가 기존에도 있었다는 이유로 통과시키지 않는다.
3. 실험 전 공학적 접촉 가정과 수용치(허용 침투/반발 범위/수렴오차/에너지 잔차)를 별도 짧은 spec에 고정한다. 물성 근거가 없으면 실제 야구 재료를 재현했다고 하지 않는다. 자유 충돌/무구동 검사와 구적법 오차를 분리한다.
4. **새 진단 profile에 한해** 접촉 설정/solver/dt 후보 비교를 허용한다. 옛 설정을 영구 동결해 문제가 방치되는 것을 피하되, 비거리 최대화로 재료를 선택하지 않는다. 기존 B1/KC 기본값은 유지한다. 새 표준으로의 적용은 통과 근거·변경 영향을 먼저 제시한다.
5. 충돌만의 검증이 통과해도 최종 몸체에 연결한 후 접촉 회귀를 다시 수행한다. 실패 시 학습 개시를 보류하고 원인/최소 수정안을 제출한다.

### B1. 파리 관절을 쓰는 최소 몸체 — 이번에는 설계/타당성 조사

1. NeuroMechFly의 원본 rig/관절축·길이·질량·관성을 확인한다. 현재 메시를 입힌3축 기구와 구별되는 모델을 설계한다. 최소 목표는 몸통을 지지한 상태에서 실제 앞다리 관절로 작은 타격 도구를 움직이는 과제다.
2. 원 스케일을 우선 검토하고 공·도구·속도를 몸의 크기/구동 가능 범위에 맞춘다. 확대가 필요하면 단위/질량·관성·토크·시간 스케일을 함께 명시한다. 원 모델의 접지 접착이나 최대 힘을 과제에 유리하게 임의 추가하지 않는다.
3. 지원된 몸통/한 앞다리 도구/양 앞다리 그립을 비교해 최소 구현안을 제시한다. 양손 폐루프가 불필요한 초기 병목이면 한 앞다리 부착 도구를 제안할 수 있으나 실제 구현 선택은 문서로 확정한다. 중간/뒷다리의 자세·실제 지지 여부도 명시한다.
4. 인간식 직립·몸통 yaw를 필수로 두지 않는다. 캐릭터 외형과 과학적 몸 모델을 구분하고 자연 관절범위를 넘는 설계는 파생 공학 모델로 표시한다.
5. 몸체/joint/action/observation 표, 도달성·출력·시각 가시성 예산, tool attachment/충돌 계약을 작성한다. 이번에는 전신 물리·균형 제어 구현을 시작하지 않는다.

## 이후 순서와 학습 진입 조건

V1과 P1은 독립적으로 진행 가능하다. B1 설계 확정 후 최소 몸체를 구현하고 무공 관절 구동/시각·접촉 통합을 검증한다. 그 후 크고 느리고 대비가 뚜렷한 공부터 시각→행동 정책 학습을 시작한다. 이는 계획상 승인된 방향이며 **이번 구현 묶음에서 대규모 RL 훈련을 시작하지 않는다**.

학습 개시 전: 입력 누출 없음, 의미 있는 가시 구간, 동작/접촉 수렴, 범위·힘 제한, 무동작으로 고득점 불가, 관절한계/겹침 exploit 없음, 평가 투구 분리 및 학습 예산/중단 기준이 필요하다. 점수는 유효한 타구 결과를 평가하고 몸통 선행/특정 자세에는 보너스를 주지 않는다. 첫 과제는 시각 반응→공 접촉→방향 있는 쳐내기→거리 향상으로 나누고 보상 버전을 기록한다.

초기 일반 정책 학습은 환경 기준선이다. 실제 초파리 회로 학습 주장은 별도 연결망/가소성·입출력 매핑과 frozen/재배선/비생물학적 정책 대조를 갖춘 후에만 한다. 기존 EXP-001 최소 기억 실험은 독립 유지하며, KC→MBON11을 바로 시각 운동 제어기라고 취급하지 않는다.

## 완료 보고

V1/P1/B1 상태를 각각 pass/fail/not-run으로 보고한다. 기존 회귀·관련 새 테스트·두 pytest 진입점·전체 lint를 실행한다. 소스/설정/seed/자산 해시와 작은 결과표는 추적하고 큰 영상은 runs에 보관한다. STATUS는 현재 상태만, 실행 근거는 records에 작업별로 남긴다. 사람식 스윙 후보 탐색으로 돌아가지 않는다.
