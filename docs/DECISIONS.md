# 설계 결정 기록

갱신: 2026-09-16. ‘확정’은 사용자 지시, ‘설계 기준’은 이번에 정리한 구현 기본 틀, ‘제안’은 아직 선택되지 않은 연구 방안이다.

## 사용자 확정

| ID | 결정 | 영향 |
| --- | --- | --- |
| D-01 | 실제 초파리 신경회로가 새로운 과제를 배우는지 연구 | 내부 가소성과 기억 검증이 중심 |
| D-02 | Codex는 계획·틀, Claude는 사용자와 구현·테스트 | 이번 변경은 문서와 인계 구조에 한정 |

## 설계 기준

| ID | 기준 | 이유 |
| --- | --- | --- |
| D-03 | 실제 연결망, 동역학, 가소성, 감각, 출력 해석을 분리 | 학습이 일어난 위치와 성능 원인을 구분 |
| D-04 | 핵심 내부 학습 조건에서는 외부 출력 해석 고정 | 출력층이 대신 학습한 효과를 배제 |
| D-05 | 단기 신경 상태·가중치·학습 trace·난수 상태를 독립 관리 | 기억 유지·제거 실험 가능 |
| D-06 | 평가용 probe에서는 보상과 가소성 비활성화 | 평가 중 추가 학습을 방지 |
| D-07 | 기존 타격 환경은 후속 인공 과제로 유지 | 연합학습을 물리환경 없이 먼저 검사 |
| D-08 | 적용 설정·출처·시드를 실행마다 보존 | 모델 재현과 조건 간 비교 |

## 연구 선택 — 상태 (2026-09-16 갱신)

`docs/PLAN.md`(D01~D09)와 `docs/design/DATA_MODEL.md`가 아래 Q-01~06의 상당 부분을 실행 기본값으로 확정했다. 이 표는 그 반영 상태를 추적한다. 개별 수치·근거는 원문서를 따른다.

| ID | 선택할 항목 | 상태 | 근거 |
| --- | --- | --- | --- |
| Q-01 | 재현 논문·프로토콜 | 해결: 원 논문(Handler 2019/Huang 2024)의 문헌 재현이 아닌 독자 규칙(`dopamine_gated_depression`) 채택 | PLAN.md D01/D02, design/DATA_MODEL.md §4 |
| Q-02 | 데이터·버전·개체 | 해결: MaleCNS v1.0 / minconf-0.5 | PLAN.md D03, design/DATA_MODEL.md §1 |
| Q-03 | 회로 범위 | 해결: KC→MBON11 부분회로(`mcns-kc-mbon11-v1`) | PLAN.md D03, design/DATA_MODEL.md §2 |
| Q-04 | 동역학·가소성 매개변수 | 해결: MBON만 LIF로 적분, KC/도파민은 외부 주입, tick별 수식과 상수 확정 | PLAN.md D04/D05, design/DATA_MODEL.md §3-4 |
| Q-05 | 자극·출력 점수·효과 기준 | 부분 해결: readout 고정·평가 중 가소성 끔은 결정(D06). A/B 자극 배정·시점·강도의 구체 수치와 통과 기준 숫자는 여전히 미정 | PLAN.md D06, experiments/EXP-001-associative-learning.md |
| Q-06 | 하드웨어·예산·반복 수 | 해결(기본값): Python 3.11, NumPy CPU, 본 평가 30 시드 | PLAN.md D07 |

Q-05의 남은 항목(자극 스케줄 구체값, 최소 효과 크기·허용 오차)은 여전히 임의 수치로 채우지 않는다. 환경 점검, 기록 구조, 물리 결함 수정은 이 표에 의존하지 않는다.

## 변경 기록 방법

결정 ID, 날짜, 변경 내용, 근거, 영향을 받는 실험 ID/버전을 함께 기록한다. 이미 완료한 실행은 이전 설정과 연결해 보존한다. 결정을 바꿔도 실패 결과를 삭제하지 않는다.
