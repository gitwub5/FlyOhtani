# ENV-002 — 야구장·투구·파리 타자 환경

계획 버전0.1 · 2026-09-16 · 사용자 요청 반영. 구현 전. B0부터 단계별로 구현하며 B1 이후의 세부 실험 규약은 각 단계 시작 전에 고정한다.

## 목표와 범위

야구장 안에서 투수가 던진 공을 타자 박스의 파리 캐릭터가 배트로 친다. 고정 직구 → 위치 변화 → 속도/타이밍 변화 → 변화구 → 혼합 투구/선구안으로 확장한다. 관측과 행동을 통일해 scripted, PPO, 신경회로 제어기를 비교한다. 야구장 작업은 EXP-001 조건화의 별도 환경 경로이며, 야구 성능만으로 생물학적 학습을 주장하지 않는다.

**기본 스케일 결정:** 구장과 공은 미터 단위의 야구 스케일, 타자는 사람 크기로 확대한 파리 캐릭터다. 외형과 제어용 간단한 몸체/배트 구조를 분리한다. 이는 시각적·공학적 기본안이며 실제 곤충 몸의 역학이 아니다. 신경 모델의 실제 뉴런 ID/시간상수는 캐릭터 크기와 별개로 유지한다. 실제 크기의 초파리 몸을 연구하는 환경은 별도 모델로 만든다.

## 1. 구장과 좌표

홈플레이트 뒤쪽 꼭짓점=(0,0,0). +x는 투수판 방향, +y는3루 방향, +z는위쪽인 오른손 좌표계. 공은 주로 -x 방향으로 이동한다. ENV-001의 +x 투구와 다르므로 관측/통과판정/controller에 부호를 하드코딩하지 않는다.

공식 배치의 참고 snapshot은 MLB가 공식 링크로 제공한 [2025 규칙집](https://mktg.mlbstatic.com/mlb/official-information/2025-official-baseball-rules.pdf), 부록1~3이다. 2026년 최신 규칙 전체를 구현한다는 뜻은 아니다.

| 항목 | 기준 / 설계값 |
| --- | --- |
| 투수판과 홈 뒤 꼭짓점 거리 | 18.4404m(60ft6in) |
| 홈플레이트 폭 | 0.4318m(17in) |
| 타자 박스 | 좌우 각각 폭1.2192m × 투구 방향 길이1.8288m; 배치는 부록2 기준 |
| 마운드·투수판·베이스·파울라인 | 공식 도면에 맞춘 배치. 잔디/흙/내야/외야는 간단한 형상으로 시작 |
| B0 파리 | 우타자 박스, 지지점 고정. 왼손 타자는 후속 좌우 대칭 profile |
| B0 공 | 질량0.145kg, 반경0.0366m인 균일 구. 검증할 모델 preset |
| B0 배트 | 길이0.85m인 간단한 강체. 두께·관성·구동 한도는 충돌/구동 검증 후 body manifest에 고정 |

파리의 발/지지점이 박스 안에 있는지 판정하며 배트의 스윙 공간까지 박스에 가두지 않는다. 몸통/배트/공의 초기 겹침을 검사한다. 외야·관중석·투수 외형은 첫 단계에서 비충돌 시각 자산으로 두고 필수 물리는 배트/공/몸/지면으로 제한한다. 야구장 장식 on/off가 동일 seed의 물리 결과를 바꾸지 않아야 한다.

## 2. 투수와 공의 출발점

투수판과 공의 실제 릴리스 위치를 구분한다. 실제 투구도 손에서 놓이는 지점이 투수판보다 홈에 가깝다. [MLB Extension 설명](https://www.mlb.com/glossary/statcast/extension)

B0의 인공 투수 preset: release=(16.5,0,1.8)m, 목표 기준면 x=0.4318m, 목표 중심 y=0/z=1.0m, 수평 접근 속도35m/s. `T=(release_x−plane_x)/35`, `v0=(target−release−0.5gT²)/T`. 이는 중력만 쓰는 단순 직구이며 실제 특정 투수의 측정값이 아니다. 초기 총속도와 수평속도를 구분해 기록한다. 손 표시와 생성 위치는 정확히 같아야 한다.

투수는 먼저 릴리스 마커/간단한 외형으로 구현한다. 이후 준비·투구 애니메이션을 추가하되 손의 release event와 공 생성 시점을 맞춘다. 공을 홈 근처에서 생성한 뒤 멀리서 날아온 것처럼 연출하지 않는다. B0에는 투수의 전신 역학을 요구하지 않는다.

공을 원하는 목표에 도달시키는 초기조건 계산은 reset에서만 수행한다. release 이후에는 외력과 충돌에 따라 적분하며, 목표점으로 매 frame 위치를 보정하지 않는다.

## 3. 타격 기구와 도달 가능한 영역

B0는 배트 높이1.0m 부근의 수평 스윙1축으로 시작할 수 있다. 기존 수직 평면의0.58m 팔과 같은 기구로 취급하지 않는다. 팔/배트 관성·충돌·torque 한도를 새 스케일에서 재측정하고 ENV-001의 gear를 그대로 복사하지 않는다.

B1의 상하·좌우 코스를 열기 전에 최소한 **스윙 + 배트 기울기/높이 조준**을 제공한다. 먼저 두 제어축으로 도달성 지도를 만들고 부족하면 몸통 위치/자세 제어를 별도 추가한다. 관절 수만 늘려 놓고 모든 코스를 칠 수 있다고 가정하지 않는다.

각 코스에 대해 유한한 구동력·준비 시간·초기 자세에서 scripted/oracle로 접촉 가능 여부를 확인한다. 도달 불가능한 공은 명시적인 볼/회피 과제로 표시한다. 학습 실패와 몸의 도달 불가능성을 구분한다. 모든 정책은 같은 몸과 행동 한도를 사용한다.

## 4. 단계별 투구 구성

| 단계 | 투구 구성 | 먼저 확인할 것 |
| --- | --- | --- |
| B0 | 고정 릴리스·고정 중심·고정 속도의 단순 직구 | 정상 궤적, 박스 배치, 준비 자세/스윙, 무토크와 제어 성능 구분 |
| B1 | 같은 속도에서 상·중·하 × 몸쪽·중앙·바깥쪽9개 코스 | 조준 제어·도달성, 코스별 성능, 한 고정각으로 해결되지 않음 |
| B2 | 연속 위치 + 속도 + 릴리스 대기시간 변화 | 타이밍 적응, 보지 않은 조합·코스 경계 일반화 |
| B3 | 공기저항·스핀 기반 직구/커브/슬라이더 | spin 방향/크기에 따른 물리 변화와 수치 수렴 |
| B4 | 구종 혼합·스트라이크/볼·지연/노고 | 보이는 공을 보고 대응, 헛스윙·볼 추격과 정상적으로 참기를 구분 |

B1 코스는 normalized (u,v)∈{−2/3,0,+2/3}²로 정의하고, 타자 profile의 zone 중심/반폭/반높이에서 실제 좌표로 변환한다. u는 몸쪽/바깥쪽 방향으로 타자 handedness에 따라 변환한다. 스트라이크존의 초기 높이 범위는0.65~1.35m인 **인공 과제 preset**으로 두고 실제 타자 자세에 따른 규칙 재현과 구분한다.

B2 후보는 수평속도30~40m/s, 릴리스 대기0.2~0.8s. 한꺼번에 모두 바꾸기 전에 위치/속도/시점을 하나씩 추가한 절제 실험을 한다. 각 단계에서는 scene/pitch/body/reward 버전을 고정하고 결과를 따로 보고한다. B3 물리를 켠 뒤에는 B0~B2의 중력-only baseline도 동일 새 물리로 다시 평가한다.

## 5. 변화구 물리의 구현 기준

첫 B3는 중력 + 공기저항 + 스핀에 의한 양력(Magnus) 모델이다. 공 속도에 따른 저항과 스핀축에 따른 힘을 외력으로 적분한다. MuJoCo rigid-body만으로 구종별 공기력이 자동 생성된다고 가정하지 않는다. 모델/계수 선택은 [Alan Nathan의 야구 물리 연구 자료](https://baseball.physics.illinois.edu/)의 원 논문·측정 자료를 검토한 뒤 문헌/가정을 나눠 별도 AIR-001 규약으로 고정한다.

필수 필드: mass/radius, air_density/wind, drag/lift 모델과 계수, initial_velocity, spin_vector_rad_s, aerodynamic_version. ‘커브’라는 레이블만으로 궤적을 미리 그리는 방식은 디버그용 kinematic profile로만 구분한다. 실밥 효과·너클볼·회전 감소 등은 최초 B3 범위 밖이다.

검증: 공기력0이면 기존 포물선, spin0이면 Magnus0, spin축 반전 시 해당 횡변위 반전, dt 절반에서 plate 위치/시간 수렴. 실제 구종의 궤적을 재현했다고 주장하려면 측정 궤적과 오차를 별도 보고한다. 목표 로케이션 맞춤은 초기속도 역산으로 하며 성공하지 못한 샘플과 이유/재시도 수를 기록한다.

## 6. 강화학습과 신경회로 비교

환경 인터페이스를 공유하되 PPO와 내부 가소성 실험을 구분한다. B0/B1은 참 공 위치/속도와 몸 상태를 관측하는 `state` profile, 이후 카메라 기반은 `vision` profile로 별도 운영한다. 서로 다른 정보량의 성능을 같은 조건처럼 비교하지 않는다.

관측에는 현재/과거 센서만 제공한다. 목표 코스, 구종 정답, 미래 plate 통과점/시각, RNG state는 정책 입력에서 제외한다. 연구용 정답은 평가 로그로만 저장한다. TTC를 넣는 경우 현재 관측에서 계산한 예측임을 명시한다. 모든 정책은 같은 관측 지연·제어 주기를 갖는다.

- 첫 단계 baseline: zero_torque, held_rest, random, scripted/oracle, constant_pose/always_swing, PPO.
- 신경 제어기 단계: 실제 연결+내부 가소성, 동일 모델 frozen, 외부 readout만 학습한 대조군. PPO를 연결했다고 뇌 내부 학습으로 보고하지 않는다.
- contact는 기계적 사건, fair contact/출구 속도/발사각/타이밍/선구안은 별도 지표다. 볼을 참은 행동에 무조건 miss 벌점을 주지 않는다.
- B0는 접촉에서 episode 종료 가능. 타구 결과를 평가하는 단계에서는 첫 접촉 보상을1회만 주고 타구 비행을 계속한다. contact phase→batted_ball phase로 전환하며 투구 통과 실패 판정을 비활성화한다.
- 보상·예산·훈련 횟수·zone별 시험 분포는 각 RL 실험 규약에서 고정한다. ENV-001의 속도 보너스를 새 스케일에 검토 없이 복사하지 않는다. 어려운 빠른 공을 우연히 맞힌 것과 제어 학습을 구분한다.

학습 seed와 투구 seed를 분리한다. 평가 투구 파일을 미리 고정해 정책별로 동일한 공을 던진다. 학습에 없는 구속×코스 조합을 holdout으로 두고, 각 코스 성공률·타이밍 분포·헛스윙/볼 추격·구종별 결과를 보고한다. 다음 단계의 수치 통과 기준은 해당 규약에 사전 등록한다.

## 7. 시계·기록·화면

초기 후보 physics_dt=0.0005s, control_dt=0.005s, neural_dt=0.001s.1제어주기에 물리10tick·신경5tick. 고속 공의 얇은 배트 통과를 막기 위한 후보이며0.00025s와 비교해 접촉 유무/plate 통과점 수렴을 확인한다. 렌더링30/60fps와 물리 step은 독립이다.

투구 로그: pitch_id/seed, curriculum, release 위치·시각, v0/spin/구종, 목표·실제 무충돌 plate 통과점, body/scene/aero 버전, 실제 접촉/타구/terminal 사건. 타격이 plate 도달 전에 발생하면 평가용 no-bat shadow trajectory에서 통과 기준을 계산해 정책에 전달하지 않는다.

화면: 야구장 전체, 포수 뒤, 타자 측면, 파리 시점. 타자 박스/스트라이크존/공 궤적/접촉점을 켜고 끌 수 있다. 리플레이에서는 실제 투구와 no-bat 기준 궤적을 구분한다. [VIZ-001](VISUALIZATION.md)의 신경 시간축과 같은 사건 시각으로 동기화한다. vision 정책 카메라에는 정답 궤적·목표 마커·신경 debug overlay가 보이지 않게 한다.

## 8. 구현 인계와 완료 단계

I-03b에서 초기 충돌·사건 순서·구동 측정 기반을 먼저 고친 뒤 **I-07a=B0 야구장/투구/파리 타자**, **I-07b=B1/B2 코스·속도**, **I-07c=B3/B4 공기력·구종/선구안**으로 진행한다. ENV-001의 짧은 거리 과제는 회귀 fixture로 유지할 수 있으나 해당 장면을 완성하느라 야구장 작업을 중복 구현하지 않는다.

I-07a 수용 조건: 공식 참조 배치/타자 지지점 검증, 손과 spawn 일치, 초기 관통0, 자유궤적 해석값 검증, frame/headless 물리 동일성, 미래 정보 누출 없음, 고정 투구의 zero-torque 대비 scripted 제어 유효성, 이벤트/리플레이 재현. B0 최초100개 평가 episode에서 held_rest/zero_torque 접촉0, scripted 접촉≥80%를 공학적 smoke 기준으로 사용한다. 결정적인 한 궤적의100회는 독립100개 학습 증거가 아니며 B1의 다양한 투구로 다음 검증을 진행한다.

I-07b/c는 단계별 실험 규약과 도달성/공기력 검증을 먼저 완성한다. 전체 야구 경기·수비·주루·카운트 전략은 이번 범위에 포함하지 않는다.
