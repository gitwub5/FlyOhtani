# I-08a-style + I-07c — 자세·색상·타구 거리 점수·스윙 개선

## 순서와 변경 경계

A. [I-08a-style](FLY-BATTING-STANCE-AND-COLOR.md): 옆선 몸통·투수 방향 머리·원본 부위별 색상. 이 단계에서는 기존 타구 물리가 불변이어야 한다.
B. I-07c-score: 동일한 물리 궤적에서 아래 점수/보상을 구현하고 예전 보상과 비교한다. 점수 변경만으로 타구가 달라지면 실패다.
C. I-07c-swing: 중앙 투구에서 준비각·가속·접촉·팔로우스루를 재설계한다. 이 단계는 물리적 제어 변경이므로 기존 출구 속도/착지와 동일할 필요가 없다. 새 물리 검증과 외형 접지/그립 검증을 모두 수행한다. A의 불변성 조건을C의 타구 개선 금지로 해석하지 않는다.

## 1. 목표: 멀리 보내는 유효 타격

지금5m 전방 gate의 성공 여부만으로는 약한 타격과 강한 타격을 구분하기 어렵다. 실제 첫 착지까지의 수평 비거리를 연속 점수로 표시한다. 스윙 궤적 자체에는 점수를 주지 않는다. 긴 스윙은 가속 거리 확보에 도움이 될 수 있지만 접촉 위치/타이밍·충돌 법선·배트 속도·발사각에 따라 결과가 달라진다. 공이 배트에서 완전히 분리된 뒤의 팔로우스루는 그 공의 비거리를 늘리지 않는다.

### 거리와 유효 판정

- `carry_distance_m`: 첫 bat contact의 공 중심에서 첫 지면 접촉 시 공 중심까지 XY 직선거리. 굴러간 거리, 배트 이동거리, 카메라 투영거리는 제외한다. 기존 carry 필드와 기준점이 같은지 확인하고 다르면 필드를 구분한다.
- `landing_range_from_home_m`: 지정한 홈 기준점에서 첫 착지까지 XY거리. 위 carry와 별도 기록한다.
- `scoring_valid`: bat contact 후 정상 분리, 분리 시 exit_vx>0, 실제 첫 착지 관측, 첫 착지가 홈 기준 전방90° 부채꼴 내부, 재접촉0 및 prolonged_contact=false인 경우. 홈 기준점/방향은 구장 좌표 정의에서 읽고 manifest에 저장한다. 부채꼴은 x_rel>0 및 |y_rel|≤x_rel로 판정한다.
- 이 판정은 **거리 실험용 전방 착지 판정**이다. 공식 페어/파울·안타·홈런 판정으로 부르지 않는다. grounder/fence/수비/주루를 다루지 않는 한 실제 야구 가치와 동일하지 않다.

### 표시 점수와 보상 v1

설계 기본값이며 생물학적 또는 공식 야구 점수라는 의미는 없다. 프로필명 `forward-carry-v1`으로 버전 고정한다.

- 표시 `batting_score = carry_distance_m` if scoring_valid else0. **1m=1점**, 소수1자리로 표시하고 내부 원값은 보존한다. 예: 유효 타구5m→5점,20m→20점,60m→60점. 별도 cap 없이 유효 범위 내에서 단조 증가한다.
- 향후 학습용 환경 reward의 정상 종료 outcome 항은 scoring_valid이면 `0.1 * batting_score`, 그렇지 않으면 -3. 기존 시간적분 제어비용 `-0.2∫(u_swing²+u_tilt²)dt`는 유지한다. 이전 접촉/gate +10을 중복 지급하지 않는다. `forward_flight_success`의5m gate는 비교 지표로 유지한다.
- 점수는 첫 착지에1회 확정하고 reward 항별 합계를 별도 기록한다. 표시 점수에는 제어비용을 섞지 않는다. reward를 추가한다고 scripted/oracle이 자동 학습하지 않으며 RL 훈련은 아직 시작하지 않는다.
- timeout/out_of_bounds로 착지를 못 보면 score는 미확정(null), status=incomplete로 기록한다. 비거리0의 정상 실패와 구분한다. 외부 truncation에는 outcome reward/실패 벌점을 지급하지 않고 소모된 제어비용만 유지한다. 비정상 종료는 별도 진단하며 보상0을 성공으로 취급하지 않는다.
- 긴 타구가 기존 짧은 episode에 잘리지 않도록 최대 비행시간/공간 범위와 관측률을 검토한다. 안전 한도는 명시하고 실제 착지 없이 해석적 외삽/가상 점수로 대신하지 않는다. 결과표에는 incomplete 비율을 반드시 포함한다.

## 2. 짧은 스윙 진단과 개선

1. 현재 중앙 타격을 기준으로 준비각, 최초 가속시각, 접촉각/시각, 제동 진입, 최종각을 기록한다. 준비→접촉 각변위와 접촉→정착 각변위를 분리하고 배트 끝/실제 접촉점 월드 궤적 및 속도, ctrl/각속도/상태 timeline을 남긴다.
2. 옆선 준비 자세에서 배트가 몸 뒤에 준비되고, 공을 향해 가속한 후 앞쪽으로 이어지는 연속 궤적을 만든다. 접촉 순간 목표각 도착만을 위해 조기 제동하지 않는지 확인한다. 접촉/무접촉 스윙 모두 한 번 가속한 뒤 부드럽게 감속·정착해야 한다.
3. 기존 gear/질량/관성/재료/dt/투구를 고정하고 준비각·트리거·목표궤적·제동 시점을 먼저 소규모 탐색한다. 한계 밖 관절각이나 몸 관통은 불가. 더 긴 준비각에 여유가 없으면 관절범위/배치의 근거를 검토하여 별도 모델 변경으로 기록한다. 점수를 올리려는 목적의 gear/반발계수 증대, 공에 힘 추가, 타구 순간이동은 하지 않는다.
4. 같은 중앙 투구에서 후보별 타구 속도/발사각/방향/비거리/점수/제어비용/접촉 지속/재접촉을 비교한다. 단순히 스윙이 길다는 이유로 채택하지 않는다. 기존보다 비거리와 표시 점수가 증가하고 전방 유효 착지·안정적 정착을 유지한 후보를 채택한다. 실패했다면 실패 원인과 최선 후보를 보고하고 개선 완료로 표시하지 않는다.
5. 선택 후보 주변 trigger ±1 control step과 physics_dt 절반의 동일 제어 일정 재생으로 접촉/착지/점수 민감도를 점검한다. 경계 사례와 판정 변화는 숨기지 않는다. 정착 목표(각 축0.5s 이내 |qvel|<0.2rad/s, 이후0.2s p-p<0.02rad)를 적용하며 기존 틸트 미충족 사항이 남으면 그대로 보고한다.
6. 새 스윙 전 구간에서 A의 두 발 접지·양손 그립·동일 배율을 다시 검사한다. 몸통 회전/새 자유도가 필요하면 최소2축 모델의 한계로 기록하고 이번에 전신 물리를 임의 추가하지 않는다.

## 3. 검증·결과물

- 점수: 같은 방향의 유효5/20/60m 착지에5/20/60점; 후방/부채꼴 밖/재접촉/미스는0점; 미확정 착지는null. 중복 지급 금지, reward 항 합계, timestep 독립 제어비용, timeout 구분을 검증한다. 합성 경계 테스트와 실제 episode를 둘 다 사용한다.
- 단계A/B는 동일 물리 결과, 단계C는 새 결과의 타당성을 검증한다. 테스트의 옛 정답 수치만 새 값으로 바꾸고 성공이라고 하지 않는다. 변경 이유와 새 기준 증거를 보존한다.
- 전후 비교표: 준비→접촉 스윙각/시간, 접촉점 속도, 출구 속도/발사각, carry, score, reward, 정착시간, 재접촉, incomplete 여부. 중앙 고정 투구 반복은 일반화나 통계적 성능 향상 증거로 쓰지 않는다.
- 위/측면 배트 궤적 그림 및 동일 카메라1× 전후 영상. 화면에는 실제 거리(m), 점수, 타격/비행중/착지/미확정 상태를 표시한다. 미확정 비행중 거리를 최종 점수로 표시하지 않는다.
- source/config/controller/보상 버전과 선택·탈락 후보, 테스트/정착 미충족, STATUS/VALIDATION_LOG를 갱신한다. 완성 시 사용자에게 영상 경로와 개선 수치를 함께 제시한다.
