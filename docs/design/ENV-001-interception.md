# ENV-001 — 제어 능력을 구분하는 타격 과제

설계 버전1.0 · 2026-09-16 · **구현 전 후보 수치와 통과 기준**. [검토 결과](../records/REVIEW_2026-09-16.md)를 반영한다. 실제 초파리 몸이 아닌 단일 관절 추상 장치다. EXP-001 신경 조건화와 독립적으로 검증한다.

## 야구장 확장과의 관계

최종 환경 목표는 [ENV-002 야구장](ENV-002-baseball.md)이다. 이 문서는 기존 오류를 분리하는 짧은 거리 검증용 과제다. 초기 관통·자기충돌·구동 측정·사건 순서 수정은 그대로 우선하지만, 여기의 거리/팔 스케일을 야구장에 그대로 이식하지 않는다. 실제 야구장 구현은 I-07a로 진행한다.

## 선택한 방향

단일 관절과 팔 길이를 유지한다. 초기 충돌을 없애고 목표점을 팔 바깥쪽으로 옮긴다. 비행시간은 짧게 하며 구동기는 충돌 없는 조건에서 다시 식별한다. 자유도 추가나 신체 확대는 후속 문제로 남긴다.

| 항목 | 첫 구현 후보 |
| --- | --- |
| 힌지 / 축 | 기존 H=(0.02,0,0.39)m / +y |
| 팔 길이·반경 | 기존0.58m / 0.018m |
| 준비각 | +0.50rad, 속도0 |
| 관절 범위 | [-1.4,+0.65]rad, 극단에서도 지면 여유 확인 |

목표는 힌지에서 약0.497m, 정렬각 약-0.2645rad이며 준비각과 약0.765rad 차이다. 준비각의 팔 끝 하단은 약0.094m다. ‘뒤로 젖혔다’는 시각적 인상으로 유효성을 판단하지 않는다. 현재 축에서 양의 회전은 팔을 아래로 내린다.

계산상 후보 준비 자세를 고정했을 때 z/T/y 각각3수준, 총27개 자유 궤적을 T의1.12배까지1ms 간격으로 표본 조사한 최소 표면 여유는 약0.166m였다. 이는 제한된 기하 검사이며 수동운동·전체 분포·수정 환경의 성공률 검증은 아니다.

## 충돌과 actuator

1. reset 직후 공·지면·팔 사이 관통은 없어야 한다. 허용 contact.dist 하한 -1e-6m. 준비 자세에서 지면–팔 거리≥0.02m를 추가 확인한다.
2. 고정 몸통과 그에 연결된 팔의 겹치는 연결부는 해당 body pair만 명시적으로 충돌 제외한다. 다른 body/ball/ground 충돌은 유지한다. 의도적으로 제외한 pair를 문서·manifest에 기록한다. 대안은 연결부 형상을 고치는 것이지만 첫 구현은 제한된 pair 제외를 선택한다.
3. 공 없이 q=+0.5에서 -0.2645까지 구동을 측정한다. 초기 충돌, 관절 한계 반발 없이 **0.35s 이내** 도달하고 NaN/관통이 없어야 한다.
4. damping0.02와 armature0.001을 우선 유지하고 gear를 [0.01,0.04,0.08,0.12] 순으로 평가한다. 위 조건을 충족하는 가장 작은 값을 선택해 `ENV-001-calibration.json`에 고정한다. 전부 실패하면 결과와 원인을 보고하고 버전을 바꿔 재설계한다. 눈대중으로 성공한 값으로 대체하지 않는다.
5. 같은 조건에서 zero torque의 q(t), qvel(t), 접촉을 함께 기록한다. 구동 성공과 수동 운동을 구분한다.

이 값들은 검증할 후보이며 생체 팔의 구동력 추정값이 아니다.

## 종료와 지표

각 substep 뒤 관측 상태를 동기화하여 contact/공 위치/속도를 일관된 시각에 수집한다. 최초 terminal 사건에서 control step을 일찍 끝낸다. 동일 substep에 공–지면과 공–팔이 모두 발생하면 `ground_contact`를 우선한다(보수적 실패 규칙). hit/miss/pass는 terminated, 외부 timeout만 truncated. 종료 뒤 step 요청은 명확한 오류로 거부한다.

- `hit`: 실제 ball–limb 접촉1회. 불필요한 속도 하한을 붙여 수동 hit를 숨기지 않는다.
- `contact_time_s`, `planned_arrival_s=T`, `signed_timing_error_s=contact_time_s−T`, 절댓값도 기록. 이는 접촉시점 오차이며 순수한 스윙 시작 오차가 아니다.
- 접촉 속도: 접촉점 두 물질점의 상대 선속도(m/s). 충돌 후 측정이면 이름에 `post_contact`를 명시; 충돌 전 값은 별도 저장 경로가 있을 때만 보고.
- 제어 비용: `−0.2 sum(action²·actual_substep_duration_s)`; 조기 종료 실제 시간만 반영. reward의 다른 기본값 hit=10, contact_speed 계수=0.25, terminal miss=-3은 유지하되 평가 성공률과 분리한다.
- 목표 x 변경을 reset/관측 TTC/controller/종료 경계/테스트에서 하나의 설정으로 공유한다. 현 하드코딩0.08/0.45를 남기지 않는다.

## baseline과 통과 기준

개발 시드0~19에서 scripted 시간 제어를 조정하고 고정한다. 권장 scripted는 남은 도달시간에서 구동 보정시간을 빼 스윙을 시작하는 방식이다. 실제 q(t)로 준비 자세를 유지하는 제어 비용도 기록한다. 시험 시드1000~1099는 튜닝에 사용하지 않는다.

비교: zero_torque(수동), held_rest(준비각 고정 진단), random(시드 고정 균등 토크), scripted(관측 기반), best_constant_angle(개발 시드로 선택한 고정각). held 계열은 상태를 강제로 고정하는 **기하 진단**이며 동일 actuator 정책 성능처럼 순위를 매기지 않는다.

첫 정비 통과: 100개 시험에서 zero_torque hit≤5%, held_rest hit=0%, scripted hit≥80%, scripted−random≥30%p. 분모·시드별 결과와 binomial Wilson95% 구간을 함께 보고한다. 임계값은 공학적 과제 기준이며 생물학적 주장용 통계가 아니다. 초기 관통·시간순서·불변성 검증도 모두 통과해야 한다. 기준 미달을 숨기기 위해 hit 정의를 변경하지 않는다.

**고정 목표점의 한계:** best_constant_angle은 높은 성공률이 가능하다. 따라서 ENV-001은 준비 자세에서 적절히 움직일 수 있는지 확인하는 smoke benchmark다. 타이밍 학습의 증거로 쓰기 전에는 목표 위치/도달시간 변화와 대기·노고 조건을 포함한 새 규약에서 best_constant_angle 및 항상 최대토크 정책을 이겨야 한다.

원자료: episode별 seed, 초기 상태, 목표/T, q/qvel/action/ball 궤적, 모든 접촉 pair·거리·시각, terminal 이유, 실제 control duration, 비용, nominal timing을 보존한다. 보고서에는 측면 궤적·팔 자세·접촉점을 겹쳐 보여준다.
