# I-08a-style — 옆선 타격 자세와 원본 색상

2026-09-16 · 사용자 요청에 따른 추가 명세. Codex는 계획만 수정하고 Claude가 구현/검증한다. I-08a-fix의64개 테스트 통과는 구현자 보고이며 이번 작업에서 독립 재실행하지 않았다.

## 목표와 범위

몸은 투수에게 옆면을 보이고 머리만 투수 쪽을 향하는 직립 타자. 앞다리2개 그립, 뒷다리2개 접지, 중간다리 접기와 전 부위 동일 배율을 유지한다. 실제 초파리의 자연 자세/목 가동범위 재현이 아닌 의인화된 시각 자세다. I-08b 전신 역학,8코스 재보정,RL은 범위 밖이다.

## 1. 몸통과 머리 방향 분리

- 카메라 화면이 아닌 월드 좌표로 정의한다. 홈→투수 수평 벡터를 p, 몸통의 해부학적 전방을 수평 투영한 벡터를 f로 둔다. 원본은 직립 변환 후 머리–꼬리축이 수직이므로 그 축을 전방으로 오인하지 않는다. 원본 배쪽/등쪽 방향과 좌우 어깨를 이용해 f 및 어깨축을 정의하고 디버그 축을 표시한다.
- 준비 자세는 f와 p가 약90°(설계 허용80~100°), 양 어깨를 잇는 축은 투구 방향과 대략 평행하도록 한다. 현재 우타자 박스 위치를 기준으로 가슴이 플레이트 쪽을 향하는 부호를 선택한다. 단순 yaw=90 숫자만으로 완료하지 않는다.
- 머리는 목 부착점을 피벗으로 별도 회전한다. 눈·더듬이·입 등 Head 자식도 함께 변환하며 머리 메시만 따로 돌리거나 분리하지 않는다. 머리의 시각적 전방축을 정의하고 투수 릴리스 위치를 향하게 한다(설계 오차10° 이하). 복안 시각/주의 방향을 생물학적으로 입증했다는 의미는 아니다.
- 이번 단계는 준비~접촉까지 고정된 투수 방향을 보는 자세로 충분하다. 공을 매 순간 추적하는 머리 애니메이션과 스윙 중 몸통 회전은 별도 후속 과제로 둔다. 새 능동 목/몸통 관절을 물리 모델에 추가하지 않는다.
- 전체 visual root 회전은 양 어깨·뒷발을 함께 이동시키므로 접지/박스 안 배치와 양손 도달성을 반드시 재계산한다. 기존 물리 batter_body/배트 피벗을 통째로 돌리지 않는다. 전 구간 도달 불능은 거리/프레임으로 보고하며 팔 늘리기나 순간이동으로 숨기지 않는다.

## 2. NeuroMechFly 원본 색상 적용

현재 generator의 strip_physics_attrs가 모든 geom에 fly_mat를 지정하고, 단색 rgba=(0.25,0.22,0.28,1)를 사용한다. 원본 STL은 유지됐지만 부위별 appearance를 옮기지 않은 상태다.

이미 취득한 flygym==1.2.1 wheel의 `flygym/config.yaml` appearance와 `flygym/fly.py`의 `_set_geom_colors`를 기준으로 부위→material/texture 매핑을 복원한다. 최신 [공식 사이트](https://neuromechfly.org/)의 시각 예시는 참고하되 패키지 버전 간 색 차이를 임의로 같은 원본이라고 부르지 않는다.

확인한1.2.1 설정 예:

| 부위 | 원본 설정 |
| --- | --- |
| 눈 | rgba (0.67,0.21,0.12,1), 적갈색 |
| 머리/흉부 | texture rgb1/rgb2 (0.59,0.39,0.12), 황갈색 + 표면 패턴 |
| 다리 | 구간별 황갈색 texture, femur→tibia→tarsus가 점차 밝음 |
| 복부 | 갈색~밝은 갈색 gradient |
| 날개 | rgba (0.8,0.8,0.9,0.3), 반투명 |

- rgba만 복사하면 몸통은 흰색이 되므로 texture의 색/패턴과 material alpha를 함께 읽는다. 동적 mocap 앞다리에도 동일 매핑을 적용한다.
- 기본안은 원본 appearance 복원. 몸통/다리 불투명화 등 가독성 변경이 필요하면 원본과 다른 값 및 이유를 manifest에 기록한다. 날개 투명도·겹침·그림자는 실제 렌더에서 확인한다.
- 원본 config/loader 버전과 해시, 가져온 항목 및 파생 material 설정을 기록한다. 난수 패턴이 있으면 재현 가능한 seed/생성 자산을 고정한다. 조명/노출을 먼저 고정하고 검게 보인다는 이유로 물리/메시를 바꾸지 않는다.

## 완료 조건과 산출물

1. 원본 자세/새 준비 자세의 정면·측면·위쪽 비교 화면. 몸통 전방·어깨축·머리 방향·투수 벡터를 겹친 진단 화면도 남긴다. 인간 목처럼90°가 가능한 실제 해부학이라는 주장은 하지 않는다.
2. 준비/접촉/정착 정지 화면과1×영상. 목 연결부, 몸통 관통, 팔 교차, 두 그립 연결, 여섯 다리 구분을 육안 점검한다.
3. [I-08a-fix](../records/FLY-VISUAL-REVIEW.md)의 양발 접지≤5mm/미끄러짐≤5mm, 양손 그립≤5mm, 부착점 추가 분리≤2mm 및 동일 배율/길이 불변을 전체 에피소드에서 재검증한다.
4. 물리 궤적·타구 결과 및 DOF/actuator/관련 질량·관성 불변. 시각 설정 변화는 정책용 영상 관측 버전에 기록한다. 기능별 의미 있는 회귀 검증과 이미지 검토를 병행한다.
5. source/derived appearance manifest와 자세 좌표 정의, 실패/도달성 측정, STATUS/VALIDATION_LOG 갱신. 테스트 통과만으로 시각 수용을 대체하지 않는다.

순서: 기존 fix 상태 보존 → 옆선 자세+목 회전과 접지/그립 검증 → 원본 색상 적용 → 비교 이미지/영상 및 회귀 검증. 범위 확장 없이 구현자가 진행한다.
