# P1 — 독립 충돌 검증 사전 등록 spec

id: CONTACT-VALIDATION-P1 · status: pre-registered before any run below ·
2026-09-17 · 기준: `docs/tasks/VISUOMOTOR-PIVOT.md` P1 · 구현:
`scripts/p1_contact_isolated.py`, `envs/assets/contact_validation_p1.xml`

이 문서의 수용치는 **결과를 보기 전에 고정**한다. 실행 후 결과가 나쁘다고
기준을 완화하지 않는다 — 특히 약 5cm 침투가 기존 KC-01a/B1에도 있었다는
사실은 이 기준을 통과시키는 근거가 아니다(`docs/tasks/
VISUOMOTOR-PIVOT.md` P1 item 2의 명시적 지시).

## 1. 분리 실험 구성

배트·몸통 제어 전부 제거. 두 개의 독립 실험, 둘 다
`envs/assets/contact_validation_p1.xml`(새 최소 자산, B1/KC-01a XML과
무관):

1. **공 vs 고정 타격면**: 공을 알려진 속도로 고정된(관절 없는, world에
   용접된) 평면 geom에 발사한다. 고정 표면은 외부 지지 반작용이 있으므로
   "자유계 운동량 보존"을 요구하지 않는다 — 튕겨 나온 공의 운동량 변화가
   지지 구조로 흡수되는 것이 물리적으로 정상이다.
2. **공 vs 자유 배트**: 같은 공을 질량 0.9kg·캡슐(반지름 0.025m, 길이
   0.85m) 자유 배트(자유 joint, 초기 정지)에 발사한다. 이 계는 외부 지지가
   없으므로 **공+배트 전체 운동량은 보존돼야 한다** — 이 보존 여부 자체가
   검증 항목이다.

두 실험 모두 production 값(공 반지름 0.0366m, 질량 0.145kg,
solref=(0.0002,0.01), solimp=(0.9,0.95,0.0001,0.5,2), 배트는 default
class solref=(0.01,1))을 그대로 재현한 뒤 timestep/solver를 바꿔 가며
비교한다.

## 2. 측정량

매 실행마다: 최대 관통 깊이, 접촉 지속시간, 반발계수(COR = 분리 후
법선속도/접근 법선속도), 충격량, 에너지 수지(KE_전 = KE_후 +
소산에너지(COR로 결정) + 잔차).

## 3. 사전 등록 수용치 (실행 전 고정)

| 항목 | 수용치 | 근거 |
| --- | --- | --- |
| 관통 깊이 | ≤ 30%×min(공 반지름, 배트 반지름) = ≤0.0075m | 공학적 여유 기준(강체 근사가 의미 있으려면 관통이 접촉체 크기의 일부 이내여야 한다는 상식적 기준) — 실측 반발계수 문헌값에서 유도한 것이 아니다, 명시 |
| 반발계수(COR) | 0.3~0.7 | 일반적인 강체-강체 충돌이 물리적으로 그럴듯한 폭넓은 공학적 대역이며, 이 특정 공-배트 재질쌍의 실측치가 아니다(현재 XML 주석이 이미 "실제 반발계수로 검증된 적 없음"이라 명시) |
| dt 수렴 오차 | 가장 미세한 두 dt 사이 COR·관통·충격량 차이 ≤2%(또는 절대 0.01) | `docs/records/KC-01a-VALIDATION.md` A2와 같은 상대/절대 혼합 기준 |
| 에너지 잔차 | production dt에서 ≤5% of KE_전 | 순수 충돌(구동력 없음)이므로 잔차는 전부 접촉 solver 자체의 수치오차만 반영해야 한다 |
| 자유 배트 실험의 운동량 보존 | 총 운동량 변화 ≤1%×충돌 전 운동량 | 외부 지지가 없는 계이므로 위반은 실행 버그(예: 이중 스텝) 신호 |

## 4. 새 진단 profile에서만 허용되는 비교

timestep/solver/접촉 파라미터 후보 비교는 **이 새 진단 profile 안에서만**
한다. `envs/assets/baseball_park_kc01a.xml`/`baseball_park_b1.xml`의
production 기본값은 이번에 바꾸지 않는다. 후보 선택 기준은 위 표의
물리적 적절성(관통/반발/수렴/에너지)이며, **비거리나 타구 결과를
기준으로 재료를 고르지 않는다** — 이 진단에는애초에 "비거리"라는 개념이
없다(스윙/배트 각도 조준이 아니라 정면 충돌만 다룬다).

## 5. 통과 후 처리

이 분리 실험이 전부 통과해도, 실제 KC-01a/B1 몸체(배트가 스윙 중 공과
만나는 실제 기하)에 연결한 뒤 접촉 회귀(`scripts/kc01a_dt_convergence.py`
류)를 다시 통과해야 "검증됨"으로 표시한다 — 이번 P1은 그 전제조건 중
하나를 확인하는 것이지 최종 승인이 아니다. 실패 시 원인/최소 수정안을
`docs/records/VM01-P1-CONTACT.md`에 보고하고 학습 개시를 보류한다.
