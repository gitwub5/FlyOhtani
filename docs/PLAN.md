## 연구 질문과 첫 실험의 범위

사용자 목표는 실제 초파리 신경회로가 새로운 과제를 배우는지 연구하는 것이다.
계산 실험에서는 **실제 연결 데이터 + 가정한 뉴런 동역학 + 가정한 가소성**을
검증한다. 연결망만으로 실제 뇌를 재현했다고 주장하지 않는다.

신경회로 트랙의 첫 실행은 MaleCNS v1.0의 KC→MBON11 부분회로에서, 두 인공 자극 중 하나와
결합한 조절 신호가 연결 효능을 바꾸고 평가 때 구별 가능한 반응을 남기는지
검사한다. KC는 버섯체 Kenyon cell, MBON은 버섯체 출력 뉴런이다. KC 스파이크와
도파민 조절은 외부에서 주입하며 MBON만 LIF로 적분한다. **입력·도파민 회로
전체를 시뮬레이션하는 모델은 아니다.**

이 실험은 최소한의 구현·인과 검증 단계다. 연합을 저장하도록 설계한 규칙이
있으므로 양성 결과 자체는 놀라운 학습 능력의 발견이 아니다. 행동 선택, 새로운
과제로의 일반화, 실제 배선의 우위, 생물학적 타당성은 별도 증거가 필요하다.

**현재 상태(2026-09-16 문서 정리 중 재확인)**: 이 규약은 확정됐으나 **실행은
아직 시작하지 않았다.** `docs/records/STATUS.md`의 "신경회로 트랙" 절 참고 —
이전 작업표 버전이 I-04/I-05/I-06을 완료로 잘못 표시했던 문제를 정정했다.

## 단계와 완료 조건

| 단계 | 실행 범위 | 다음 단계로 넘길 증거 |
| --- | --- | --- |
| S0 기반 | I-01/I-02/I-04: 환경, 기록, 실제 회로 추출 | lock, provenance, ID/간선 검증, 합성 테스트 |
| S1 최소 기억 | I-05/I-06: EXP-001과 시각화 | 모든 비교군·기억 개입·음성 결과 포함 보고서 |
| S2 생물학 대응 | Huang 2024 공개 모델의 지정 그림·조건 재현; 시간 순서 효과 및 실제 DAN 피드백 검토 | 원 모델 재현 오차와 차이, 확장 모델의 새 규약 |
| S3 새로운 과제 | 시간 간격 구별/반응 시점 과제로 전이, 고정 회로·학습 출력층 비교 | 보지 않은 자극/시간에서 일반화, 배선 대조군 |
| S4 몸과 접촉 | I-03b 오류 수리 → I-07 야구장/다양한 투구 → 신경 제어기 통합 | 감각 정보량을 맞춘 baseline과 폐루프 검증 |

S2~S4는 방향이며 현재 구현 착수 범위가 아니다. EXP-001만 통과해 공 치기·언어·
거래 학습으로 성공을 확대 해석하지 않는다. 음성 결과도 S1 완료이며 원인을
확인한 뒤 다음 연구를 설계한다.

## 참고 연구와 역할

[Huang 2024](https://www.nature.com/articles/s41586-024-07819-w)는 버섯체의
기억 구획과 피드백을 다룬다. [공식 구현](https://github.com/schnitzer-lab/Luo_Huang_2024_MB_model)은
MATLAB 기반 축약 모델이므로 EXP-001의 개별 뉴런 LIF 모델과 구분한다.
[Handler 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC9012144/)는 입력과
도파민의 시간 관계를 다룬다. 두 연구는 메커니즘의 참고이며 여기의 수치를
제공한 출처가 아니다. 최근 데모의 학습 주장과 한계는
[리서치 검토](research/REVIEW.md)에 보존했다.

## 변경 절차

규칙·시드·판정 기준 변경 시 날짜, 변경 전후, 이유, 이미 열람한 결과 범위, 새
규약 버전을 남긴다. 본 평가 결과를 본 뒤 바꾼 규약은 탐색 연구로 표시하고 새
holdout 시드 묶음을 사전 고정한다. 결과가 좋지 않다는 이유로 시드를 제외하거나
과거 실행을 삭제하지 않는다.
